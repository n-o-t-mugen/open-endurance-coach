# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's [private vulnerability reporting](https://github.com/yannvillellas/open-endurance-coach/security/advisories/new) instead, and include:

- a description of the issue and its impact;
- reproduction steps or a proof of concept;
- the affected version or commit.

Never include real secrets, API keys, or personal health data in a report.

## Scope

This project handles Intervals.icu credentials and athlete health data. Reports about credential leakage, prompt injection through athlete data, or unauthorised calendar writes are especially welcome.
